# Dataset Information

The project uses the UCI Online Retail Dataset.

Dataset:
UCI Online Retail

Source:
https://archive.ics.uci.edu/dataset/352/online+retail

The dataset contains transaction records from a UK-based online retail
business.

Important variables include:

- InvoiceNo
- StockCode
- Description
- Quantity
- InvoiceDate
- UnitPrice
- CustomerID
- Country

The original dataset is not stored in this repository because it is
automatically downloaded by the Google Colab notebook during execution.

## Dataset Usage

The dataset is used for:

- Data cleaning
- Exploratory data analysis
- Revenue analysis
- Customer segmentation
- Anomaly detection
- Relationship analysis
- Hypothesis testing
- Revenue prediction
